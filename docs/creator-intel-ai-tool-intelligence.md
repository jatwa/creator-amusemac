# Creator Intel — AI Tool Intelligence

The Tools layer is designed around filmmaker decisions, not generic directory listings.

## Decision graph

IDEA → RESEARCH → CREATIVE DECISION → DIRECTOR'S INTENT → SHOT DESIGN → MODEL SELECTION → PROMPT → GENERATE → COMPARE → REFINE

## Tool dossier relationships

Tool → Techniques → Prompts → Workflows → Comparisons → Films → People → Research → Journal → Updates

Every tool should explain what it does, when to use it, when not to use it, relevant filmmaking roles, production stage, capabilities, pricing/commercial terms, examples, tutorials and connected resources.
